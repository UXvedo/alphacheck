Methodology

AlphaCheck publishes estimates, not financial advice. This page is the skeleton for the audited write-up. The formula sections below are unfinished on purpose. The live calculator still follows How it's calculated until the audit replaces that text.

Assumptions

  • Every figure is an estimate from one chain snapshot. It is not a quote, a fill, or a prediction.
  • Rewards over the holding period use simple interest. Emission rates and pool reserves are held constant except for the alpha-versus-TAO scenario you choose.
  • A validator take is applied. Pages that show a single case use 18%. The calculator lets you change it.
  • Root staking is modeled with no AMM slippage. Subnet staking goes through that subnet's pool on the way in and on the way out.
  • Nothing on this site is a recommendation to stake, unstake, or prefer one subnet.

Data sources

Snapshots are read from the public Bittensor Finney RPC, subtensorModule storage: pool TAO, pool alpha, alpha outstanding, alpha emitted per block, and the root proportion. The site ships the latest pull as public/snapshot.json. The line at the top of this page is that pull's UTC timestamp and block. Each pull also stores one record per subnet in data/history/ (one file per UTC day). No private API key is used. A Taostats adapter is sketched in src/data.js and is not wired.
